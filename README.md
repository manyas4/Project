# Electricity Consumption Trends Prediction (India)

This project is a Streamlit-based interactive dashboard that analyzes electricity consumption patterns across Indian states and predicts future per capita electricity consumption using machine learning.

The application integrates data visualization, economic analysis, renewable energy assessment, and predictive modeling to support energy planning and policy-level insights.

## Project Features

### 1. Category-wise Electricity Consumption
- Sector-wise electricity consumption analysis
- Identifies dominant consumption sectors per state
- Based on official sector classification

### 2. Installed Capacity and Power Generation
- Source-wise installed capacity and electricity generation
- Comparison between renewable and non-renewable sources
- State-level insights

### 3. Renewable Energy: Installed vs Potential Capacity
- Comparison of installed and potential renewable capacity
- Utilization percentage calculation

### 4. Economic Analysis of Electricity Consumption
- Relationship between per capita electricity consumption and GSDP
- Multi-state comparison using interactive visualizations
- Population and income-level impact analysis

### 5. Future Electricity Consumption Prediction
- Machine learning-based prediction using Linear Regression
- Inputs: Year, Per Capita GDP, Population
- Output: Predicted per capita electricity consumption

## Machine Learning Model
- Algorithm: Linear Regression
- Features: Year, Per Capita GDP, Population
- Model saved using Pickle

## Tech Stack
- Python
- Streamlit
- Pandas, NumPy
- Plotly
- Scikit-learn
